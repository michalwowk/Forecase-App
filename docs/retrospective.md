# Retrospective

An honest note on the state of the code and how the work went.

## Code quality
- I am not fully satisfied with the code as it stands.
- Part of it was not reviewed in enough depth. Treat it as working, not as reviewed.

## What went wrong
- Scope and quality bar were too high for a few hours of work.
- Too much time went into research, planning and steering the agent, too little into review.
- As a result I lost some control over what the agent produced.

## What I would do differently
- Cut scope earlier to fit the time box.
- Review each build step before moving on, not at the end.
- Spend less time on process, more on the code itself.
